# Bundled catalogue artwork

All 20 SVG images in this directory are original vector illustrations authored for Interior Moodboard in September 2026. They depict generic furniture and material studies; they are not product photographs or manufacturer designs. No external source images, trademarks, remote fonts, scripts, or network resources are embedded.

The project author may use, modify, and distribute this artwork with the application. No third-party attribution is required. The SVG title identifies each image; `src/data/assets.ts` supplies stable IDs, labels, categories, local paths, and the exact width/height aspect ratios from the SVG roots.

Furniture illustrations use transparent backgrounds for collage placement. Material studies are square swatches. Catalogue records describe reusable assets; board placements store separate instance IDs and reference asset IDs.
