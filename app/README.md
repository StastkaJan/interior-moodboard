# Interior Moodboard app

React, strict TypeScript, Vite, and CSS Modules. Run the app and quality commands through Docker Compose from the repository root; see ../DEVELOPMENT.md.

The scaffold was generated with the Compose Node 24 image, resolving to Node v24.21.0. ESLint, Prettier, TypeScript, and Vitest supply the quality scripts. `npm test` runs once and allows an empty suite during the scaffold ticket; no feature tests exist at this stage. Browser testing is pending IM-13.
